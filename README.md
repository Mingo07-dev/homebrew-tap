# Homebrew tap for Ammugghia

[Ammugghia](https://github.com/Mingo07-dev/Ammugghia) is a native macOS disk cleaner for
developers that refuses rather than guesses.

```bash
brew install --cask mingo07-dev/tap/ammugghia
```

Update with `brew upgrade --cask ammugghia`. `brew uninstall --zap --cask ammugghia` also
removes Ammugghia's own index, history, logs and preferences; it never touches anything
Ammugghia cleaned.
